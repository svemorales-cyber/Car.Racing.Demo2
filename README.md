# KOD Racing - T 

A 3D arcade street racer that runs in the browser (Three.js). There's no build step: open `index.html` or host it on GitHub Pages.

## Main menu
The game opens in the workshop with your car on the turntable, like the menus of console racing games. Everything is in one place: **Race** (a quick race against bots), **Multiplayer**, **Garage** (cars, paint, tuning) and **Settings** (graphics, sound, camera and the list of controls). After a race the results show up in the same menu.

## Playing with friends (multiplayer)
1. Open **Multiplayer**, type your name and press **CREATE ROOM**. You get a 5-letter room code.
2. Once the room is created you pick the track there (the room shows it to everyone). Send the code to your friends, or press **Copy invite link** and send them the link (it opens the game with the code filled in).
3. They open the game, go to **Multiplayer**, enter the code and press **JOIN**. Up to 4 players fit in a room.
4. The host picks laps, difficulty, time of day, weather and whether bots fill the empty grid slots, then presses **START RACE**. Everyone starts together, sees the others' cars with their names above them, and gets the same results table at the end.

How it works: the players' browsers connect directly to each other (WebRTC, using the PeerJS library). The free PeerJS server is only used to find the room. The host's browser runs the bots and passes the positions on, so **the host has to keep the game open** for the whole race. Nothing has to be installed or hosted: it works from GitHub Pages. On strict networks (some home routers, mobile data, school or office networks) a direct connection isn't possible. The game then tries public TURN servers, and if that fails too it switches by itself, after about 10 seconds, to a relay over secure websockets (free public MQTT brokers). The relay is a bit slower but works almost everywhere. The cars' positions go 30 times a second over a second, unordered line (a lost packet doesn't hold up the ones behind it), and each car is drawn where it is right now on its driver's screen: the game measures the ping, lines the packets up on the sender's clock and carries the car forward by its speed and turn rate over the network delay, blending out small misses instead of jumping. The lobby shows each player's ping (green under 80 ms, yellow under 160 ms, red above; "relay" when the relay carries it). Both players must run the same version: it is shown at the bottom left of the menu and in Settings. After an update, reload with Ctrl+F5. If the free PeerJS server is ever down you can run your own (`npx peerjs --port 9000`) and open the game with `?peer=your-server:9000` added to the address. `?forcerelay` skips the direct connection and `?relay=wss://your-broker/mqtt` uses your own MQTT broker.

## Protection against cheating
- **Signed save.** Credits, wins, upgrades and records are saved with a signature. Changing anything in the browser's storage (F12 → Application → Local Storage) makes the signature wrong: the game refuses that save, starts over and says so in the menu. (Saves from before this version were plain text that anyone could edit, so they are not carried over.)
- **Stock cars online.** In a multiplayer room the host can pick **Cars: Stock (fair)**. Then everyone races the factory setup of their car, whatever they bought in the garage (or hacked into it).
- **Obfuscated build.** `sh build-dist.sh` (needs Node.js) makes a `dist/` folder: the same game, but `js/game.js` goes through `javascript-obfuscator` (settings in `obfuscator.json`), so the variable names are gone and the code is very hard to read or change. **Upload the contents of `dist/` to the site, not the source.** If the source files are in a public GitHub repository anyone can still read them there, so keep the source in a private repository (or only on your computer) and publish only `dist/`.

Be aware that nothing that runs in the browser can be made 100% cheat-proof: a determined person can always pick the code apart. Real protection would need a server that keeps everyone's credits and checks race results. These steps stop the easy tricks.

## Features
- **Tracks**: pick one of three in the race menu; the circuit and everything around it is rebuilt on the spot, without reloading the game. In multiplayer the host picks it (also from inside the room) and everyone's game switches with them. **KOD Grand Prix** (3.3 km): a long main straight, fast sweepers, a chicane, a back straight, a hairpin and twisty esses. **Imola** (2.9 km), traced from the real circuit: the Tamburello and Villeneuve chicanes, the Tosa hairpin, Piratella, Acque Minerali, Variante Alta and the double left of Rivazza. **Suzuka** (3.6 km), also traced from the real one: a figure of eight with the esses, Degner, the hairpin, Spoon and 130R, where the back straight climbs over the rest of the lap on a bridge. Each track keeps its own records. Every track has curbs, ad-board walls, a start gantry with countdown lights, a grandstand full of 3D spectators (some stand up and cheer), street lamps, a city skyline, trees and mountains.
- **Start / finish like a modern GP circuit**: the main grandstand is 180 m of concrete terraces with blue seats (and the odd yellow and orange ones) full of fans, a glazed hospitality level on top and a white tensile roof on steel arches, sagging between the modules with a lattice mast at each joint. The start gantry is two tapering lattice towers with an arched truss across the track, a sponsor banner on both faces and the start lights hanging underneath. The pit building has a sponsor band with the garage numbers over the doors, a floor-to-roof glazed first floor and a white wave of roof over each bay; the pit lane is light concrete with a red band along the pit wall, and each team has a white kiosk on the pit wall with its colour on the roof, tinted windows and a camera on a pole. The catch fences lean in over the track at the top, the grid slots have their numbers and yellow lines, and the grandstand side of the main straight has a green verge.
- **Run-off and gravel traps**: on the outside of the corners the barrier stands up to 15 m further back, from before the turn-in to well past the exit, with a light sand-coloured gravel trap in front of it, so a car that runs wide ploughs into the gravel (and slows down) before it reaches the wall. Along some straights there's a wider band of gravel too, different on each side. The barrier, fence, banners and posts follow it. None on the pit straight, by the start or around the bridge.
- **Trackside**: brake boards (150, 100, 50 m) before the big corners, marshal posts with marshals waving green flags, TV camera towers and fans on the grass banks at corners, sponsor bridges over two straights, a big screen at the first corner, hospitality tents behind the grandstand and a row of flags along the main straight.
- **Tyre physics** (C++): each axle has a slip angle and a tyre curve that peaks and then falls off, so grip builds up, reaches a limit and then lets go. Steering, braking and throttle share the same grip (friction circle), and weight moves to the rear when you accelerate and to the front when you brake. Turn in too fast and the front washes wide (understeer); too much power or lifting mid-corner swings the rear out (oversteer). Each car has its own weight balance and drivetrain: front-engined cars push wide, the rear-engined RENNER rotates, and the all-wheel-drive KAZE R34, RENNER and TORO put their power down cleanly where the rear-drive cars can slide. In the rain the tyres have less grip, let go earlier and slide more once they have. The little tyre icon next to the damage bar shows how much grip each axle is using: green has grip left, yellow is at the limit and red is sliding. Light stability control and anti-lock brakes stop the car from spinning on every mistake. The engine pulls with full force up to about a third of top speed and then runs out of power (force falls with speed, like a real engine's power curve); air drag grows with the square of speed on top of rolling resistance; lifting off the throttle gives engine braking; and in hard corners the weight on the outside tyres costs a little grip. With a controller, throttle, brake and steering are analogue.
- **Acceleration**: the cars pull like real GT cars, 0-100 km/h in about 2.6 to 4 seconds depending on the car (and the bots pull the same way: full thrust low down, then the power runs out with speed), instead of shooting off like rockets.
- **Drifting**: pull the handbrake (Space) or give it too much gas in a rear-drive car and the tail steps out. Hold Space for a moment to kick the tail out; keep holding it (or just stay on the gas) and the car carries its speed through the slide instead of stopping. Stay on the gas to keep the slide going. Steer into the corner for more angle, counter-steer to straighten up (hold the counter-steer on the gas for a moment and the car swings through into a drift the other way, a flick, so linking left and right drifts is easy), or let go of the steering and the car catches the slide by itself. The front wheels visibly counter-steer, the camera swings out to show the car sideways, and the harder you slide the thicker the tyre smoke. You get skid marks and drift points, and the nitro bar fills. A held drift is a way round the corner, not off it: the slide keeps about the same cornering force as driving on grip (a bit tighter when you steer into the turn, wider when you counter-steer), so in a long fast corner a drift holds the line instead of sliding into the wall, at the cost of some speed. The slide angle is held by a close to critically damped controller, so a held drift is steady (no wobbling back and forth or a pull towards the other side), and counter-steering straightens the car smoothly instead of flicking it into a slide the other way. The tyre smoke is ragged, see-through puffs that fade in, spread, turn and thin out, and the body leans from smoothed forces, so it no longer wobbles like jelly.
- **Nitro**: press Shift to boost. You get blue flames, speed lines and a wider field of view. Driving over the blue boost pads refills nitro and gives a burst of speed.
- **Super start**: press gas just before "GO!" for a launch boost.
- **Smarter bots**: they follow a racing line, brake for corners, overtake, use nitro on straights and bump into you.
- **Options**: 1/3/5 laps, 3 difficulties, and day/sunset/night. At night the lamps light the road, building windows glow and your car has a working headlight.
- **Speedometer**: an analog km/h dial like in Need for Speed or Assetto Corsa. It has a needle, a rev ring that lights up blue → yellow → red with a flashing shift light, a digital speed readout, the current gear and a nitro gauge. The dial's scale follows your car's top speed, so upgraded cars get a bigger scale.
- **HUD**: an F1-style timing tower top left: a red header with the lap and your position, a row per car with its colour, a three-letter name and the gap to the leader (measured every 20 m, so it's a real time gap; PIT while a car is in the pit lane, DNF when it's out), your row in white, and the race time, current lap and best lap underneath. Also a minimap, a damage bar, a wrong-way warning, a results table at the end, and records saved in your browser. Sound is switched in Settings (or with M).
- **Pop-ups**: the little bonus messages (boost, super start, drift score) can be switched off in Settings → Pop-ups.
- **Realistic graphics**: filmic tone mapping, and the sky lights and reflects off everything. The sky has a scattering-style gradient, a sun halo and puffy cumulus clouds lit from the sun side (dark undersides, bright silver edges) with thin cirrus above. Distant things fade into an aerial-perspective haze that thins with altitude and turns warm when you look towards the sun. The asphalt has stone grain, sealed cracks, resurfaced sections, polished tyre lines and worn paint. The grass verges are mown in light and dark stripes, and further out they turn into a rough meadow with straw-coloured patches, tufts and wildflowers. Trees grow in groves and come in four kinds (oak, birch, poplar and pine) with leaf, needle and bark textures that stay full at any distance. Buildings come in glass, brick, concrete and ribbon-window office styles with several colour variants, blinds and curtains in the windows, weathering streaks, shop fronts, roof units and randomly lit windows at night. The mountains have forest cover, rock bands and snow caps. Cars have glossy clear-coat paint, reflective glass, tyres with tread and sidewall lettering, mirrors, a grille, number plates, exhaust tips and door lines. All textures are generated in code, so there are no image files. Run-off areas are gravel traps of rounded, mixed stones; the catch fence is thin galvanised wire with tension cables and a top rail; the grass has short and long blades, clover and darker long grass against the barriers, and woods of broadleaf trees, birches, poplars and pines grow close to the circuit.
- **Sound**: engine sound that changes pitch with gear and speed, plus tyre squeal, crashes and countdown beeps. All sound is generated in the browser, so there are no sound files.
- **Touch controls** on phones.
- **Rain**: thousands of rain streaks drawn on the graphics card that fall at a raindrop's real speed, drift with the wind and stretch towards you as you speed up; splashes and little crowns of droplets where they land; a darker, glossy road with puddles that mirror the sky and ripple with rings from the drops; mist thrown up behind fast cars; drops on the screen; and lightning with thunder. The car has less grip and longer braking (handled in the C++ physics), and the bots drive more carefully.
- **Finish replay**: after the finish line you see the last seconds again with cinematic camera angles (trackside, low, orbit, helicopter) and slow motion at the finish line. Press Enter or click to skip.
- **Crashes and rollovers**: cars bump each other with real momentum (equal masses, a little bounce): a hit pushes the other car and spins both if it's off-centre: the push goes through the other car's bumper or door, so tapping a rear corner of the car in front swings its tail round and spins it out (a PIT manoeuvre). A hard hit from any direction (into the side above about 40 km/h, into the front or back above about 55 km/h, from another car or the wall) turns it into a 3D rigid body (simulated in C++: gravity, the box's corners hitting the ground, friction, wheels that roll): it flips, rolls, slides on its roof and lands where physics puts it. If it lands on its wheels it drives on; on its side or roof it's put back on its wheels after a moment. Rollovers dent the car, throw sparks and dust, and show up in the replay and for the other players online. No two rollovers are the same: a softer hit can lift the car onto two wheels and drop it back; harder ones send it rolling, barrel rolling several times, flipping end over end (hits from the front or back), corkscrewing with a twist, or flying through the air. Impacts push and spin cars harder than before.
- **Damage**: hits against walls and other cars dent the bodywork where they hit (lights, mirrors, grille and wing move with the panel they are on) and fill the damage bar. Wall collisions use the car's real outline, so a car that hits the barrier sideways or backwards can't poke through it, and the camera stays on the track side of the fence. A damaged car smokes, catches fire when badly hurt, and loses top speed and acceleration (C++ physics). With the "Damage pull" race option on (RACE OPTIONS button in the race menu, where extra race rules live), crashes bend the steering: the car pulls towards the side that took the most damage, and front-corner hits bend it more than hits at the back; off (the default), it still drives straight. Dents are deep and creased like real crumpled metal, and a hard hit tears off lights, mirrors, the wing and trim: they fly off with the car's speed, tumble, bounce and stay lying on the track until the next race. Cars are built to take a beating: each crash does about half the damage it used to, and parts break more slowly.
- **Broken parts**: where a hit lands decides what breaks. The nose takes the engine (less power, then misfires with flames from the exhaust) and a front wheel; the tail takes the rear wing (less downforce in fast corners) and a rear wheel; the sides take their wheels; the brakes wear from every big hit. A wheel past 70% is a flat tyre: the car loses grip and speed (and with the Damage pull option on, wobbles and pulls to that side), and sparks fly off the rim until you get to the pits. Like in F1, a car status panel under the minimap shows a top view of the car with the wings, tyres, engine and brakes coloured green / yellow / orange / red, next to the team radio messages ("PUNCTURE FRONT LEFT · BOX BOX", "ENGINE DAMAGED · CAN'T BE FIXED").
- **Panels come off**: every hit adds up on the panel it lands on (bonnet, front bumper, left door, right door, rear wing). Past its limit the panel tears off and flies down the track (dents and all), and the hole shows the dark inside: the engine bay, the door frame. A lost wing costs downforce. The crew puts everything back in a pit stop; when a car blows up every panel goes. Online everyone sees the same panels come off. (The KAZE GT35, built from a 3D model, only loses its wing.)
- **Pit lane**: like in F1, a pit lane splits off on the left before the finish line (a white line marks the entry), runs behind a concrete pit wall with a catch fence past the pit building and joins the track again after the start. The pit building looks like an F1 one: one garage and box for every car in the race (online: one per player, in the same order on every screen), each in that car's colour: the name over the door, a big team logo on the back wall, team stripes inside, timing screens hanging from the ceiling, tyres in team-coloured blankets and a spare front wing on its stand. Each box is painted in the team colour with the name and wheel marks, has a light rig with a traffic light over it, front and rear jacks, air lines for the wheel guns and fresh tyres ready, and opposite it the team's stand on the pit wall, with engineers at their screens under a roof in the team colour. The crews are F1 mechanics in team overalls (with a contrast band and side panels), gloves, boots and full helmets with a chin guard and a dark visor; ours have jointed arms and legs, so they run out to the car swinging them as you come down the lane, kneel at the wheels with the guns and lean on the jacks; the bays at the ends stay shut. Flags fly on the roof. In the lane an 80 km/h speed limiter switches on by itself, and cars pass through each other from the entry line until they are back on the track, so nobody gets rammed in the pit. Your box is the yellow one, with a rig and traffic light over it, tyres in blankets and a crew in your colour: tyre gunners at all four wheels (two on each side of the car, they stay at the wheels until the stop is over), a tyre carrier by each wheel with the new tyre, jack men front and back with long-handled jacks and a lollipop man; the other teams' crews wait by their garages. Pit stops work like in F1: once you cross into the lane the game takes the car (through the same inputs a gamepad gives the physics) and drives it on the limiter into your box, square on the marks. The crew runs out of the garage as you come down the lane, the jack men push their handles down and the car rises, the wheel guns whirr with a puff at each nut, the old wheels come off and the tyre carriers step in and push the new ones on, then the jacks drop, the lollipop flips to green and the crew walks back into the garage (round the nose or the tail of the car, never through it). The camera cuts to a TV shot from the pit wall as you pull into the box. The stop takes as long as the work: about 2.5 s for tyres, longer for bodywork, a new wing or brakes, with an F1-style stop clock at the top of the screen (it turns green with the final time). Press the gas to leave early with what's done so far. Then the car is driven out on the limiter and handed back to you at the end of the lane. A damaged engine can't be fixed in a pit stop. The pit lane is drawn in yellow on the minimap.
- **Critical damage and explosions**: the damage bar fills gradually. Past 85% the car is in a critical state (a big warning for a moment, then a blinking red warning triangle stays right under the small car status picture on the right; on a big screen it sits beside it): the next real hit, or reaching 100%, and the car blows up in a fireball, every part and a spray of panels, plastic and glass scatters over the track and stays there, and the burnt shell rolls to a stop. You are out of the race (DNF, shown last, no credits). Bots can blow up too.
- **Limp mode**: when the engine is failing (or the whole car is critical) the car's computer goes into limp mode: about half the acceleration (0-100 km/h takes twice as long), top speed 20% lower, and the engine hiccups to a new power level every 1-2 seconds with a short dip, so the car shudders on the straights. It sounds sick too: lower, rough and choking, with pops and bangs from the exhaust when you lift off. DRS is locked shut.
- **DRS**: on the two longest straights of each track. Cross into the zone less than a second behind the car ahead and DRS is enabled: the flap opens by itself on full throttle (less drag, about 6% more top speed, a little less downforce) and shuts when you brake. A light above the damage bar shows it: grey in a zone, green when enabled, bright green when open, red and struck out in limp mode.
- **Cars**: the KAZE GT35 has a body from a real 3D model (windows and the carbon wing are drawn by the paint shader along the car's lines, so any colour from the garage works). The other cars are built in code. Seven models with curved bodies built in code, each inspired by a real car (the names are made up): VELOCE GT4 (mid-engine coupe), KAZE R34 (Japanese turbo coupe), RYU S15 (drift coupe), STALLION GT (V8 fastback in the style of a Mustang), RENNER TURBO S (rear-engine coupe in the style of a 911 Turbo S), TORO V10 (wedge supercar in the style of a Huracán) and APEX HYPER (hypercar). Each has its own lights, intakes, exhausts, an interior seen through the glass, and detailed wheels.
- **Car bodies**: the cars built in code have real side windows from the A-pillar to the C-pillar, with the pillars left in body colour between the glass, and road-car wings: a ducktail or none on most, a low GT wing on the hypercar (the garage still offers every wing).
- **STRADA GT1**: the eighth car, built from a full 3D model of a mid-engine Le Mans GT1 road car (long tail, big wing). tools/build_gt1.mjs turns the SketchUp OBJ into the game model: the model's wheels are dropped (the game draws its own, so rims and paint work as on every car), the rest is grouped by material into body, trim, metal, glass, head and tail lights and cabin, scaled to its real 4.71 m, turned nose-forward, simplified from 150,000 to about 17,000 triangles for phones and compressed to under 200 KB. Available from the start.
- **Garage**: a workshop (block walls, roller doors, tool cabinets, tyre racks, a car lift) whose reflections show up in the paint. It has with a category menu (Car, Paint, Wheels, Aero, Performance, Setup), a car carousel, performance class badges and live stats (top speed, 0-100 km/h, horsepower, handling, braking, nitro). Hovering an upgrade shows its gain in green. You can choose the paint colour, finish (gloss, metallic or matte), rims, caliper colour and rear wing.
- **Tuning**: seven upgrade categories (engine, turbo, nitro, tyres, brakes, suspension, weight reduction) with 5 stages each, bought with the credits you win in races. There are also two setup sliders: gearing (acceleration ↔ top speed) and balance (grip ↔ drift). Fully upgraded, a car gains about 15% top speed (25% more with nitro) and about 70% more acceleration, so it feels stronger without turning into a rocket. All of this is computed in the C++ physics.
- **Controller**: any standard Xbox / PlayStation / other gamepad works as soon as you press a button. RT gas and LT brake are analogue (part throttle, part brake), the left stick or d-pad steers, A is the handbrake, B or RB nitro, Y camera, X back on the track, Start pause. In the menus the d-pad moves a highlight between the buttons, A presses and B goes back. It rumbles when you crash.
- **Race options**: the RACE OPTIONS button opens extra rules: boost pads on or off, and damage pull.
- **Multiplayer lobby**: every player presses READY; the host can only start once everyone is ready. If the host changes a race setting, everyone has to press READY again.
- **Contact between friends**: when your car hits a friend's, your game takes your half of the impulse and sends a hit to theirs, which pushes, spins, damages, dents or rolls their car on their screen, the same way it works with the bots. Dents, parts torn off, explosions and pit repairs are sent to everyone, so all of you see the same battered cars and the same debris on the track.
- **Ghost start**: for the first 5 seconds after the lights go out cars pass through each other, so a perfect launch can't end in a pile-up at the first corner. The other cars look see-through while there's no contact (also in the pit lane).
- **Settings** (from the main menu or the pause screen): graphics quality, sound on/off, music on/off, volume and camera. **Graphics High / Low**: High adds ambient occlusion (soft contact shadows where things touch), bloom, a colour grade with vignette, bigger and sharper sun shadows, live reflections of the surroundings on your car, and about 38,000 grass tufts. Low turns these off for weaker computers and phones; phones start on Low.
- **Music**: a synthwave track generated live in the browser that gets more intense on the last lap. You can turn it off in the menu.
- **Controls written in C++** and compiled to WebAssembly (see below).

## Loading fast (cache and models)
- **Service worker** (`sw.js`): on the site (https) the browser keeps the game after the first visit: the page, `game.js`, the physics (`controls.wasm`), the car models, three.js and the font. The next visit loads from the phone's or computer's memory, and a race works without internet (online multiplayer still needs it). The page itself is always checked online first, so a new version shows up at once; each version has its own cache (`kod-racing-v40`...), and the old one is deleted when the new one is in. Not used when you run the game locally (add `?sw` to the address to try it there).
- **Car models**: `models/*.glb` are already compressed with meshopt and quantized (`EXT_meshopt_compression`, `KHR_mesh_quantization`), about 150-200 KB each, with no textures. Draco would hardly make them smaller and needs its own decoder (about 200 KB more to download, and slower to unpack), while the meshopt decoder is 25 KB, so the game stays with meshopt. `tools/build_car.mjs` does this for new cars.

## Changing the controls (C++)
1. Edit `controls/controls.cpp`. For example, change the `kActionKeys` table to rebind keys, or change a car's numbers in the `kModels` table (top speed, acceleration, grip...) to change how it drives.
2. Rebuild: `sh controls/build.sh`. You need `clang` and `wasm-ld`: on Ubuntu run `sudo apt install clang lld`, on macOS run `brew install llvm`, on Windows install LLVM from llvm.org.
3. Upload the new `controls.wasm` together with `controls.cpp`.

Keys are matched by their physical position (`KeyboardEvent.code`), so the controls also work with a Bulgarian (Cyrillic) keyboard layout.

## Running it
The browser only loads `controls.wasm` and `js/game.js` from a web server, so the game will not start if you just double-click `index.html`.
- **GitHub Pages:** upload all files, then go to Settings → Pages → Deploy from branch → `main` / root. The game will be at `https://<your-username>.github.io/<repo-name>/`.
- **On your computer:** start a small local server in this folder, for example `npx http-server` or `python -m http.server`, then open the address it prints.
